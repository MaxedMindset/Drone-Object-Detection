# birds_helicopters.v4i.yolov11

## Beschreibung

Dieser Datensatz wird ausschließlich für die Evaluierung verwendet.

Er enthält Bilder von

- Drohnen
- Vögeln
- Hubschraubern
- Flugzeugen

Der Datensatz ist **nicht Bestandteil dieses GitHub-Repositories**, da er aus einer sehr großen Anzahl an Dateien besteht.

## Download

https://universe.roboflow.com/jahnavi/birds_helicopters

## Verwendung

Nach dem Download den Inhalt des Datensatzes in diesen Ordner kopieren.

```
birds_helicopters.v4i.yolov11/
├── train/
├── valid/
├── test/
└── data.yaml
```
