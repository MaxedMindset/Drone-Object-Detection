# drone_dataset

## Beschreibung

Dieser Ordner enthält den Trainingsdatensatz für das YOLO11-Modell.

Der Datensatz ist **nicht Bestandteil dieses GitHub-Repositories**, da er aus sehr vielen Einzeldateien besteht und das Repository dadurch unnötig groß werden würde.

## Download

https://www.kaggle.com/datasets/sshikamaru/drone-yolo-detection

## Verwendung

Nach dem Download den Inhalt des Datensatzes in diesen Ordner kopieren.

```
drone_dataset/
├── images/
├── labels/
└── data.yaml
```
