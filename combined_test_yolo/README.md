# combined_test_yolo

## Beschreibung

Dieser Datensatz wurde im Rahmen unseres Projekts erstellt und dient ausschließlich zur finalen Evaluierung des trainierten YOLO11-Modells.

Er kombiniert den Drohnendatensatz mit dem Evaluierungsdatensatz, sodass die Standard-YOLO-Metriken berechnet werden können.

Da der Datensatz aus sehr vielen Dateien besteht, wird er nicht zusammen mit diesem Repository veröffentlicht.

## Erstellung

Der Datensatz kann mit den im Repository enthaltenen Python-Skripten aus den beiden ursprünglichen Datensätzen erneut erstellt werden.

```
combined_test_yolo/
├── images/
├── labels/
└── data.yaml
```
